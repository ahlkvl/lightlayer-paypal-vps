## 常见问题

**PayPal 账户所在的地区不支持怎么办？**
这是 PayPal 那一侧的限制，商家没法绕开。如果 PayPal 走不通，LightLayer 还支持支付宝和信用卡。

**能不能靠 PayPal 争议把钱要回来？**
PayPal 争议是平台机制，商家的退款政策是另一套规则，两条线互不覆盖。商家页面写的是只赔自身责任，PayPal 那边受不受理、判不判给你，是独立流程。把“能开争议”当成“一定能退”，是这类支付方式上最常见的误判。

**续费会不会涨价？**
查不到 LightLayer 关于续费价的公开说明。首期价和续费价是不是一致，进客户中心看续费账单最准，别按“首年便宜、次年翻倍”的行业惯例替它推。

**可以先月付再转年付吗，或者反过来？**
资料里没有升级、降级、周期切换的规则说明。这类操作通常在客户中心的面板里完成，下单前确认一遍。

**支持哪些付款方式？**
PayPal、支付宝、信用卡。2024 年底只有前两种，信用卡是后加的。
